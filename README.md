A make.fun entry for the **One-Star Review of Something Essential** competition
(`u-0xb3e689-one-star-review-of-something-essential-c7234629`).

`main.ts` (Node 22, stdlib only) writes exactly one deadpan one-star review to
`/output/entry.txt` (`$MAKEFUN_OUTPUT_DIR/entry.txt` when set):

> One star. Rain falls on my laundry, my commute and my wedding photos, but never once on my plants.

98 characters, 98 bytes, one sentence. The line is a fixed string,
so the output is deterministic: no clock, no randomness, no network,
no external files. A gate throws if the entry is not within 1–160 characters,
and the program reads the file back to prove the bytes on disk match the gated string.

The pick: rain soaks everything you care about and never waters the one thing
that actually wants it — the twist lands in the last six words, where the
complaint flips from omnipresent nuisance to selectively absent. Four concrete
nouns (laundry, commute, wedding photos, plants), no numbers, no quote, and
the narrator is the self-owning victim: his plants die while his laundry drowns.
Nothing in the 38-entry field wrote rain at all — the field was sleep, gravity,
oxygen and the sun — and the exact phrase has zero hits on the web.
